# 校准记录：2023 国赛 C 题（蔬菜类商品的自动定价与补货决策）

> 证据库：来自 2023 C 题官方评分细则、评阅细则补充说明、出题人评阅综述的蒸馏
> （BZD-review-paper 校准记录整理，广东赛区评阅材料）。
> 用途：训练期对照练习、赛后复盘对照。**比赛项目不需要拷贝本目录。**

## 官方评分结构（历史口径，共 100 分）

| 类别 | 分值 |
|---|---|
| 摘要与论文写作（各 5） | 10 |
| 问题 1（分布与关联基础） | 25 |
| 问题 2（品类级联合决策优化） | 35 |
| 问题 3（单品级带约束优化） | 25 |
| 问题 4（数据建议） | 5 |

**权重逻辑（依赖加权）**：Q1 不是描述统计——它的分布结论喂给 Q2；Q2 是中心耦合决策故最高；Q3 因改变决策粒度+组合约束获高分；Q4 短定性扩展。

## 封顶锚点（官方，训练时当红线）

- Q1 只做描述统计+可视化、无分布律 → **封顶 10/25**
- Q2 耦合关系只用简单回归/拟合 → **C23-21 封顶 7/10**
- 相关性方法忽略适用性假设（Pearson 不检验正态性/线性）→ **实质扣分**
- 先预测后定价的分离式流水线（不表达耦合决策）→ 按弱方案处理

## 出题人评阅综述：高影响失败清单（写作时逐条自查）

1. 销售缺口/异常批发价未清洗或清洗不合理
2. **均值填充非销售记录 → 扭曲需求与利润**（本年度头号坑）
3. 分布分析浅：无季节性、节假日、概率拟合
4. 相关性方法不做适用性检验
5. 定价与补货**独立建模**而非联合
6. 解释"满足品类需求"时忽略多样性
7. 决策变量/优化结构不清晰、元启发式不解释
8. 利润/定价/补货结果不可信、无工作日/周末区分

## 迁移规则（换到任何"数据+决策"题）

1. 每个显式子问题 → 独立可观察的评分项
2. 结果被下游复用的问题权重更高（做扎实）
3. 数据题给异常/缺失/零值处理显式分值（影响需求估计）
4. 题面说耦合就奖励联合机制模型；浅层串行拟合封顶
5. 题面每个数值操作要求 = 一个评分约束
6. 结果必须有场景区分（日期/季节/工作日）
7. "收集更多数据"题按用途+可行性双标准评分
8. 官方推荐方法只是锚点不是强制——方法适配+论证充分即可满分
