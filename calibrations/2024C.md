# 校准记录：2024 国赛 C 题（农作物种植策略）

> 来源：2024 C 题赛题 + 官方赛后专家评述《农作物的种植策略赛题评述》（无官方分值表，证据锚点取自评述）。
> 用途：大规划优化题的判分口径参考。比赛项目不需要拷贝本目录。

## 负面锚点与封顶（官方评述的常见失败）

1. **违反任一强制农艺约束的方案 = 无效优化结果**（目标值再漂亮也没用）——可行性先于最优性
2. 模型、算法、表格**三者必须一致**，约束与利润可独立复算
3. 逐年/逐季独立求解**普遍丢失轮作与三年豆类耦合**——跨期耦合必须保留
4. **不要假设所有土地都要种**——过剩产出无价值时，闲置可能才是最优
5. 启发式无可行性检查、无计算资源/基准对比/重复实验 → 不能声称最优
6. 正式 MIP 半途放弃、换一个无关启发式 → 模型-求解部分不得满分

## 可迁移教训（适用于任何大规划题）

1. 大规模规划题：**机器可查的可行性**给足分，其次才是目标质量
2. **硬约束与软管理偏好分开**，并暴露两者的权衡
3. 数学规划要报求解器状态/上下界/gap；启发式要报基准对比统计
4. 跨期决策必须保留跨期耦合（轮作、库存、复利）
5. 不确定性与相关性任务：可复现的情景生成 + 样本外/风险评估
