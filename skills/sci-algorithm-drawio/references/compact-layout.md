# 紧凑度与字号：操作规程

## 1. 使用最终图宽，不使用显示器放大倍率

图形坐标字号 F、实际导出宽度 W、最终论文图宽 M 毫米时，估计字号为 F/W×M×72/25.4 pt。必须用完整导出范围，包括外侧标签、回路与边距。该比例计算是自定义排版估算；真实字体度量、富文本、导出与排版仍要检查。

160 mm、1000 单位宽时，F=22 约 9.98 pt；宽1600 时同样的 F 约 6.24 pt。增大 PNG 分辨率不能修复这种相对比例错误。字号应随真实插图宽度预算，不随“画布越大越专业”的直觉。

普通标签目标 9.5–11 pt、次要注释8.5–9.5 pt、低于8 pt通常拦截，是本技能默认，不是引用期刊规范。若单栏85 mm仍塞不下，改结构、拆必要局部或使用允许的跨栏，不能仅把字缩小。

## 2. 内容驱动的四级计算

文字：按真实字体测量，或用保守估计做初稿。单行宽度＋左右padding；多行按最大行宽和行数算高度。

模块：包含标题、对象和局部标记；不要只按最长英文单词猜中文宽度。优先控制一至两行，不堆全文。

组：子对象包络＋短标题带＋小边距。先移近子对象，再收缩组边界。仅缩组而不动子对象不能消除内部空洞。

整图：按已排好的阶段、支路、回路反算外边界。不要固定16:9、A4横版、四栏等高；论文图不是演示页。

## 3. 明确三种间距

- 组内：最近、稳定，体现同组。
- 组间：略大于组内，用于区分，不需要多倍放大。
- 走线通道：按实际线数、线间距、箭头与标签计算，不能无条件保留宽走廊。

为转折而留出的空白必须实际承载线路。没有线路或区分职责的大空白，优先删掉。刻意对照的一对对象可以保留对比间距，写入计划。

## 4. 空白审核，而非“墨水占比”

不要把白像素比例当指标：白底框内文字、真实留白、图片、浅灰填充会使这种指标失真。

使用以下可解释诊断：
1. 每个组的内容包络距边界有多远？标题下方和底部是否有大空带？
2. 声明为同组相邻的一对模块，净距是否超过约1.4F且没有线路／标签原因？
3. 全图边界是否被孤立标签、绕远的回线或散件撑大？
4. 是否存在可放下一个普通模块的大空区，而且与路由和层次无关？
5. 框内标签占据的高度是否远小于框高？是否为保持全图等高而产生空尾？

叶子对象面积／内容包络面积只是诊断代理值，不规定全图必须达到某百分比。容器底色不算有效内容；不得扩大文字框或加无意义图元“刷密度”。

## 5. 压缩操作的正确顺序

核实结构 → 锁住最终字号 → 简化重复文字 → 紧化模块内部 → 对齐支路 → 压组内距离 → 子组边界收紧 → 简单阶段收窄 → 缩短回路 → 重布余下冲突线 → 裁整图 → 实际尺寸看图。

若压缩导致箭头无法辨认，局部恢复必要间隙；若整图仍宽，不整体缩小字体，而应更换结构／拆局部。不能新增算法内容填空。

## 6. 自动检查边界

`audit_layout.py`只读已声明几何，字号为比例估计；文本容量是字符宽度启发式，非字体排版引擎；组松散与间距为风险提示；路由只检查明确的规划折线，编辑器自动路由尚未确定时标unknown。程序不生成图片，不保证字体或箭头已通过目视验收。

建议在场景中写 `layout.adjacencies` 指定需要检查的邻接关系，以及 `layout.exceptions` 说明必要大间距；没有声明不能假称已穷尽所有空洞。渲染时仍逐区检查空白。
