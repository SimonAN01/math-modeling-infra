## 关键取舍

| 材料或旧框架说法 | 本轮处理 |
|---|---|
| 问题分析必须一问一节 / 不得拆二级标题 | 默认自然段，复杂任务可设具体小标题；只强制任务覆盖与依赖真实 |
| 摘要800—1000字、综述500字、假设4—8条、文献至少5篇、表格最多15行 | 均作为参考建议；不成为提交门槛，不凑数 |
| 每问必然递进、问题三固定是改进模型 | 只按实际输入输出关系衔接 |
| 公式只给“用”不给“源”、不做收敛说明 | 保留关键推导与依据；求解需停止条件及匹配的收敛/稳定性证据 |
| 线性规划因此采用模拟退火 | 改为与问题类型适配的求解器；启发式需理由与最优性边界 |
| 所有符号必须进全局表 | 全局主要符号入表，局部符号就近定义 |
| 摘要数字必须逐字一致 | 数值同源、单位与舍入一致，显示精度变化可追溯 |
| 请队外人员读摘要、赛中让教师审稿 | 改为队内检查；教师反馈限赛前/赛后训练 |
| 凭AIGC检测或有数字判定人工撰写 | 删除此类断言；文风与真实性、披露核验分别处理 |
| 评分观察点就是官方百分制 | 明确第三方内部量表；先冻结、凭证据评分；保留可选90%单项封顶并说明理论最高90 |
| 格式质量乘数、经验分数推位次 | 默认不使用，材料未提供充分可复算定义与本题校准 |
| 声明必须100—180字并扩充固定用途 | 保留官方二选一原句，只从真实台账概括用途，不为长度扩写 |
| AI工具不必作为参考文献 / 一律禁止涉及AI的文献 | 工具使用走披露；真实研究文献按论证需要引用，不作主题封禁 |
| 参考文献只占附加页，或必须与声明各新开页 | 声明、参考文献纳入30页正文预算；不强制二者分别新页 |
