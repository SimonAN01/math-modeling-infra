# 模型假设

依据 S12、S14。假设由团队决定；AI可检查必要性、矛盾与影响，并整理已确认内容。

## 先登记，再写正文

在 `03-models/assumption-register.md` 区分题面条件、由题意/数据支持的推断、模型需要的补充假设。每条记录依据、简化对象、作用位置、失效影响及验证办法。仅状态为团队确认的条目可进入论文；六维审查继续使用原有 model-review。

正文采用编号条目，关键假设补充简短解释。数量随实际需要，不凑4—8条。不要假设模型正确、结果可靠或数据毫无错误；预处理步骤本身不是假设。清洗完成也不自动证明数据有效，需明确剩余数据满足哪些具体条件及适用范围。

独立、正态、平稳、参数固定等条件须有题意、理论或数据证据；证据不足时明确其假设性质和检验计划。不能忽略题目要求研究的核心因素。假设的作用可以落在公式、边界、参数估计、检验或局限分析，不要求硬塞成约束。

## 可复制提示词

> 对照题面、数据记录、团队模型方案和 assumption-register，审查假设。逐条列出类型、依据、必要性、后文使用位置、冲突、失效影响及验证办法。正文仅整理团队已确认假设；新建议放入待确认表，不能替团队批准。不得虚构独立性、分布、平稳性检验，不得把清洗步骤或“模型合理”写成假设。数量按实际需要。输出 LaTeX 条目和登记表修订建议。

## 验收

- [ ] 无与题面矛盾、循环论证、重复或未使用条目。
- [ ] 实际数据处理与数据假设一致。
- [ ] 关键简化保留核心因素，适用范围与风险清楚。
- [ ] 模型改变后相关假设已回到待复核状态。
