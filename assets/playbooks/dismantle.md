# 拆题机：题面 → 结构化拆题产物

> 自动生成流水线的第 ① 站。输入题面全文 + 附件数据说明，输出两份结构化文件
> （`problem-brief.md` 总纲 + `question-map.md` 每问地图）与创新卡候选。
> **产出契约**：下游所有生成器（数据机 / 建模机 / 组装机）只认这两份文件的结构，
> 字段名不许改。写完跑 `scripts/dismantle <目录>` 校验，全 PASS 才算拆题完成。

## 〇、读题面三遍法（各抓一层，别混着读）

1. **第一遍抓"要交什么"**：输出要求、结果形式（数值/表格/排序/方案）、提交物清单
2. **第二遍抓"给了什么"**：附件数据字段、题面数字约束（每一个数字都是一条评分约束，judge-view 迁移规则 5）、显式条件
3. **第三遍抓"没说的"**：隐含目标（成本 vs 覆盖、效率 vs 公平）、隐含约束（非负/容量/时效/守恒）、前后问依赖（Q1 输出喂 Q2？）

## 一、生成流程（每步产出写哪）

### 第 1 步：填 problem-brief 总纲

9 要素逐格填（竞赛/题号/目标/子问题列表/已知与未知/输出要求/时间约束/模板路径/成稿语言），
然后：

- **题型判断表**：每问一行，类型（预测/评价/优化/分类/数据关系/组合）+ 主推方法 + 备选
- **隐含信息四查**：多目标？现实约束？前后传递？业务常识约束？逐项打勾

### 第 2 步：题型判定（决策树，写进题型判断表）

按结果呈现方式判主类型（judge-view 第五节）：

- 要**最优解/策略/方案** → 优化类（A）
- 要**统计规律/相关/显著** → 数据关系类（B）
- 要**排序/打分** → 评价类
- 要**未来值外推** → 预测类
- 有目标函数+约束、又要预测 → 组合（预测+优化），**别误判成纯优化**

判定句模板（每问写一句）："这一问要的是 __（输出），本质是 __ 类问题，因为 __。"

### 第 3 步：每问填 question-map 十要素

逐格填：输入 / 输出 / 决策变量 / 约束条件 / 可用方法 / 验证方式 / 隐含目标 /
隐含约束 / 链条关系 / **创新候选**（对照 `innovation.md` 五类型找特殊结构，
有则写明候选方向，没有就写"无"——**不硬造**）。

**可用方法格 = 选型判断句**（12 张表选完必须回答）：为什么是它、前提是否成立、
结果怎么验证、答辩守不守得住。方法名后面跟依据，不裸写名字。

### 第 4 步：画依赖图（写进"链条关系"）

- Q1 的什么输出喂给 Q2/Q3 的哪一步？逐条写清
- **下游复用的问题权重更高**（judge-view 迁移规则 2）——被下游依赖的那问要做扎实
- 官方评分结构参考：2023 C 题 Q1:Q2:Q3 = 25:35:25（中心耦合决策最重）

### 第 5 步：创新卡候选（国一档门票）

每问按 `innovation.md` 第 1 步找"特殊结构"：课本模型没有的约束？耦合不能拆的量？
递归/时序依赖？数据特殊几何？找到 → 写一张创新卡草稿（类型+针对结构+动机一句话）；
找不到 → 创新候选写"无"，本问按"扎实组合"（国二档）做。

### 第 6 步：评分锚点映射（写进 question-map 每问的"约束条件"与"输出"）

题面每个显式要求 → 一条可观察证据。例："单品补货量不低于 2.5kg" → 约束行
"x_i ≥ 2.5（题面要求，答辩可查）"。漏一条 = 少一个评分点。

## 二、完成标准（机器门）

跑 `scripts/dismantle <项目目录>` 校验：

- [ ] problem-brief 九要素无 `{{}}` 残留
- [ ] 题型判断每行有类型 + 主推方法
- [ ] 隐含信息四查全打勾
- [ ] question-map 每问十要素全填、无 `{{}}`
- [ ] 每问有"一句话建模思路"

**修复循环**：FAIL → 补对应格 → 重跑，最多 3 轮；3 轮不过 → 人工介入
（连续补不出来说明题没读懂，回读题面，别靠猜填空）。

## 三、输出契约（下游生成器依赖，不可改字段名）

`question-map.md` 每问的表格键：`输入 / 输出 / 决策变量 / 约束条件 / 可用方法 /
验证方式 / 隐含目标 / 隐含约束 / 链条关系 / 创新候选`。
`problem-brief.md` 的键：`竞赛名称 / 题号 / 题目目标 / 子问题列表 /
已知数据与未知量 / 输出要求 / 时间约束 / 模板路径 / 成稿语言`。
