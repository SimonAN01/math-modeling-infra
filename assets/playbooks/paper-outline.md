# 论文结构与篇幅

章节写作入口见 [writing-workflow.md](writing-workflow.md)。默认使用 CUMCMThesis 与 XeLaTeX；结构按题目调整，不强制固定章数或模型数。

## 内容分工

| 部分 | 核心内容 | 验收依据 |
|---|---|---|
| 标题、摘要、关键词 | 背景与任务、逐问方法和结果、必要检验 | 最后反写，和正文证据一致，首页一页 |
| 问题重述 | 简短背景、逐问任务；研究综述可选 | 对象、条件、范围、输出不变 |
| 问题分析 | 数学类型、数据限制、路线理由、依赖及验证计划 | 自然段优先，任务覆盖完整，不提前报结果 |
| 模型假设 | 必要的团队确认假设与理由 | assumption-register 中可追溯 |
| 符号说明 | 主要全局符号、含义和单位三线表 | 全文及程序口径一致 |
| 模型建立与求解 | 逐问模型、参数依据、算法、结果和解释 | 六维审查、实际代码、结果版本 |
| 检验与灵敏度 | 独立验证、关键参数扰动和适用边界 | 可在各问内或集中成章，避免重复 |
| 模型评价与结论 | 有证据的优缺点、回答、局限与条件性推广 | 区分已完成改进与未来设想 |
| AI声明、参考文献 | 真实披露与规范引用 | 声明在参考文献前；均计入正文页数预算 |
| 附录 | 支撑清单、环境运行说明、完整源码、必要补充 | 与实际支撑包及正文同版本 |

共用数据较多时，在模型章前或章内设置公共数据处理；只服务某一问的数据放该问，部分共用则“公共处理＋专属处理”。不固定增加独立的第五章。建模章节通常按题目顺序组织，小节标题应说明内容，最多三级为宜；内容少时可合并，但每个子任务仍须可定位。

## 页数预算

先根据任务重要性、模型复杂度、依赖与检验需要分配篇幅；不知道官方分值时不得虚构。下表由团队按实际填写，全部正文（含AI声明和参考文献）不超过30页；摘要与附录另计。不要将声明、参考文献挪出预算，也不要将核心答案藏进附录。

| 部分/问题 | 目标页数 | 实际起止页 | 模型/结果/检验是否齐备 | 超额处理 |
|---|---|---|---|---|

压缩时先删重复背景、方法历史和重复图表，再将全量明细移入附录/支撑材料，保留完整模型、主要结果与必要推导。15行表格、800—1000字摘要、500字综述等仅为参考建议。排版可读性优先，不用缩小到难读的字号凑页数。

## 公式、算法与图表

标准方法简述并引用，题目特有的推导、假设、约束和近似条件必须讲清，不能“只给公式不给依据”。优化模型集中写目标、约束和变量范围；机理、统计、评价问题按实际数学结构表达，不强套优化模板。

算法可以用步骤段或算法环境，均需输入输出、参数、初值、种子（适用时）、停止条件和实际求解状态。启发式求解不能仅凭找到一个解就宣称全局最优。正文说明关键环境和求解器版本，附录给完整环境与运行命令。

图题在下，表题在上，用编号在正文引用，变量和单位可辨；同组信息只在图表互补时并用。表格用 booktabs 三线表。流程图展示任务联系，算法框展示计算步骤，不为相同信息重复画图。

## LaTeX入口

项目入口为 `05-paper/main.tex`，模板示例 `CUMCMThesis/example.tex` 是说明资料。电子版使用 `\documentclass[withoutpreface]{cumcmthesis}`，不用承诺书、编号页或目录。标题命令为 `\title{}`，关键词为 `\keywords{}`，不能套用其他模板的命令。可按需要启用黑白打印选项。

公式用 `equation` / `align`，配 `\label` 与 `\eqref`；图表用 `\ref`，若使用 `\cref` 先确认对应宏包。更新版式或引用后至少编译两遍，检查实际PDF及未定义引用。附录新页开始便于核算正文；参考文献与AI声明是否单独开页按版面与赛区要求处理，不认为全国强制分页。

各章缺口、核验状态和修订优先级留在工作记录，不进入最终论文。定稿前经过 humanizer-zh，但语言润色不得改变事实、数值或技术含义。
