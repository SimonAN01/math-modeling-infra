# 模型评价、改进与推广章节写法（第十一章）

> 收官章：先报**优点**（具体到模型与数据），再报**缺点**（每条配改进方向），
> 最后**推广**到相似场景；`结论` 按题目问数逐段对应，只总结已证明的内容。

## 章节结构

```
十一、模型评价、改进与推广
├── 11.1 模型的优点（3--4 条，每条具体到模型/数据/方法）
├── 11.2 模型的缺点与改进（2--3 条，每条缺点 + 一个具体改进方向）
├── 11.3 模型的推广（本题方法 → 哪些相似场景）
└── （结论：按问数逐段，每段报该问的结果与意义）
```

## 11.1 优点怎么写得"具体"

| 差写法（空话） | 好写法（具体） |
|---|---|
| 模型具有较好的精度 | 预测 MAPE 均低于 8%，满足日补货决策的精度要求 |
| 考虑了多种因素 | 同时纳入需求、补货、定价、损耗四类约束，且每条约束有业务依据 |
| 方法具有创新性 | 用 K-means++ 先聚类再分组建模，将 108 种单品降为 6 个品类，大幅降低求解规模 |
| 结果具有实用性 | 输出"补货量 + 定价"可执行策略表，商场可直接按表操作 |

优点条目控制在 **3--4 条**，每条都能从正文找到支撑（表、图、公式编号）。

## 11.2 缺点必须配改进方向

规则：**每个缺点后面必须跟一个可落地的改进**，不允许只批评不改进。

| 缺点（诚实） | 改进方向（具体） |
|---|---|
| 损耗率取历史均值，未考虑天气 | 接入天气预报数据，建立损耗率与温度/湿度的回归修正 |
| 模型按品类整体定价，未到单品粒度 | 在品类内引入单品价格弹性系数，逐单品定价 |
| 模拟退火为启发式，不能保证全局最优 | 小规模算例与 CPLEX 精确解对比验证，误差 <2% |

缺点的写法技巧：**缺点写"边界"而不是"硬伤"**——"模型假设了需求服从正态分布"这类边界性缺点，配合"用分布检验+非参数方法兜底"的改进，既不伤印象又显严谨。

## 11.3 推广

写 2--3 句，把本题方法映射到相似场景：

- "本模型以'数据画像 → 预测 → 优化决策'为主线，可直接迁移至生鲜电商选品、连锁药店补货等相似决策场景"
- 推广句里出现的场景要真的相似（同样的决策结构），不硬凑"可用于金融、医疗"这类泛泛之谈

## 结论（按问数逐段）

- **几问就写几段**，每段：这一问做了什么 → 关键结果数字 → 结论含义
- 只总结**已证明**的内容，不引入正文没有的新结论
- 段首可直接用"针对问题一……"起，保持与摘要、正文结果三方一致
- 最后可用 1 句收全文（如"本文的建模流程可作为同类数据驱动决策问题的参考"），不额外发散

## 禁忌

- [ ] 长篇自我批评（缺点 2--3 条即止，且都配改进）
- [ ] 优点写空话（"科学""合理""有效"不出现——出现了就是空话）
- [ ] 推广硬凑场景
- [ ] 结论按问数对不上、或引入新结果

## 自检

- [ ] 优点 3--4 条，每条能在正文找到对应表/图/公式
- [ ] 缺点 2--3 条，每条都有具体改进方向
- [ ] 结论段落数 = 题目问数，数字与摘要、结果文件一致

## 句式模板（填空即用）

> 【】= 换成你题目的词与数字。

**优点句（每条 = 方法 + 方面 + 数字）**：

> 【模型 / 方法】在【方面】表现【具体数字】：如"温特斯乘性模型对各品类 MAPE 均低于 8%，满足日补货决策的精度要求"。

**缺点 + 改进句（缺点写边界，改进写具体）**：

> 【边界性缺点：损耗率取历史均值，未考虑天气因素】。改进方向：【具体做法：接入天气预报数据，建立损耗率与温度、湿度的回归修正】。

**推广句**：

> 本模型以【主线：数据画像 → 预测 → 优化决策】为主线，可直接迁移至【相似场景：生鲜电商选品、连锁药店补货】等决策场景。

**结论句（按问数逐段）**：

> 针对问题X，本文【做了什么】，得到【数值】，说明【含义】。（只总结已证明内容，不引入新结果。）
