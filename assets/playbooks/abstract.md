# 摘要最后反写

依据 S06、S08。输入为完成的正文、检验、结论和 `05-paper/evidence-map.md`；结果未核验时只整理证据缺口，不生成装作完整成果的摘要。

## 内容结构

开头通常两句话：简要说明对象与现实背景，再引出核心任务。不要使用“随着……发展”的空泛开场，也不要在开头塞满方法清单。

主体按题面顺序，通常一问一段。每段讲清任务、关键数据或条件、模型及建模思想、求解方法、代表性结果和必要检验证据。覆盖子任务，不因模板只有四问而遗漏或新增问题。前问确实给后问提供输入才使用承接句；独立问题明确独立，不强行递进。

结果优先报数值、单位、区间或可执行方案；定性任务如实给规律或建议，不硬造数字。报告误差或提升时说明指标、基准与口径。结尾可简述正文已有证据的特色、局限或推广条件；没有证据就省略，不用空泛总结凑段落。

题目准确表达研究对象与核心任务，可包含主模型，但不堆模型名。关键词通常4—6个，覆盖对象、主要模型和算法，按内容选择。摘要中避免图表、公式、文献编号和未解释的缩写，保证脱离正文可读。

## 可复制提示词

> 仅根据完整论文和已核验的 evidence-map，反写题目、中文摘要及关键词。先核对每问方法、算法、结果、单位、检验与正文位置。开头用简短背景与任务引入，主体按真实问题顺序说明任务—方法—求解—结果，必要时给检验。按实际依赖衔接，不预设问题三是不确定性或改进模型。不得补造数字、实验、创新、推广效果和参考文献。输出 LaTeX 标题、abstract和keywords，另列摘要论断与正文/结果版本对照及缺口。篇幅以含标题关键词的一页为准，不为800—1000字或固定段落强行增删事实。

## 验收

- [ ] 每个子任务有对应回答，方法与正文一致。
- [ ] 数值与结果同源、单位和舍入一致；显示精度不同须记录换算，不能要求无意义地逐字相同。
- [ ] 比较基准、误差口径与适用范围清楚，无新增结论。
- [ ] 每个论断能回到正文或证据表；尚未完成的检验未写成成果。
- [ ] 由队内成员完成独立可读性检查；赛期不邀请队外人员审读赛题相关内容。
- [ ] 最终PDF首页包含标题、摘要、关键词并控制一页；无模板提示残留。

措辞检查只用于提高表达质量，不能由语气或检测分数证明作者身份或学术诚信；真实过程记录与人工核验单独保留。
