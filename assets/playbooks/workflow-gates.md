# 数模工作流门禁与回退

这份手册把项目推进从单向清单改成可回退的证据链。每个门禁都要留下简短记录；未通过时回到产生问题的阶段，不用整题重跑。

## 阶段门禁

### 1. 建模门禁

- `01-problem/question-map.md` 的问题数量与题面一致。
- `03-models/assumption-register.md` 已区分题面条件、支持性推断和补充假设。
- `03-models/model-review.md` 的六维审查通过。
- 每个优化模型已做可行性预检；每个回归或交互模型已记录共线性处理和回退形式。

不通过：回到拆题、数据记录或模型审查，不进入 `03-models/code/`。

### 2. 结果门禁

- 当前结果版本有 `04-results/<版本>/run.md`，包含输入、代码版本、命令、随机种子、参数和输出。
- 预测任务有训练/验证或测试划分；优化任务有约束检查和求解器状态；评价任务有指标方向、归一化和权重来源。
- 论文要用的每个定量结论已登记到 `05-paper/evidence-map.md`。

不通过：回到数据处理或求解阶段。不要在论文中用未经登记的结果。

### 3. 图表门禁

- 数据图只由真实结果生成，并能回溯到结果版本。
- 非数据图有可编辑源文件和导出 PDF。
- 算法图先核对算法事实和连接关系，再决定布局；必要时使用 `sci-algorithm-drawio`。
- 每张图或表在论文中都有“为什么需要、读者看什么、支持什么结论”的相邻文字。

不通过：数据图回到结果阶段；算法图回到图示阶段；解释不足回到写作阶段。

### 4. 写作门禁

按以下顺序处理：

1. 只使用已确认的模型、结果和证据；
2. 用 `math-modeling-text-object-integration` 衔接正文、公式、图和表；
3. 用 `math-modeling-three-line-tables` 检查表格类型、比较口径和标记；
4. 用 `paper-launch-polish` 组织核心贡献和证据主线；
5. 编译后再做数值和版式检查。

不通过：数值或证据问题回到结果阶段；论证和表达问题留在写作阶段；模板或编译问题回到排版阶段。

### 5. 提交门禁

`06-submission/checklist.md`、论文、结果版本、支撑材料和 AI 使用记录必须指向同一版结果。任何一项变更都要把受影响的证据行标为“待复核”。

## 回退记录

在 `handoff.md` 或 `05-paper/evidence-map.md` 追加三项：

```text
发现问题：
回退阶段：
重新核验的文件：
```

只重跑受影响的子问题和下游产物；无依赖的结果保持不动。
