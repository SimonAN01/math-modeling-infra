# 评委视角与评审要点

> 写论文时用它自查"评委眼中你会被扣什么分"，提交前与 `06-submission/checklist.md` 一起过。
> 提炼来源（一手整理资料）：
> - 国赛评审标准整理：https://github.com/landawang-star/shuxue-jianmo-lunwen-pingshen
> - BZD-review-paper 评审 Skill（近五年国赛评阅细则蒸馏，含 2023 C 题出题人评阅综述）：https://github.com/BZDmathclub/BZD-review-paper
> - 2023 C 题（蔬菜定价与补货）评分细则与评阅补充说明——即 C050 国一论文的赛题

## 一、按赛题决定权重

自评重点是合理假设、数学正确性、求解与验证、结果完整和表述清楚。本框架不将固定的20%/25%等比例称为官方权重，也不按文献数量决定奖项。正式内部评分使用 `review-rubric.md` 的流程，根据完整赛题筛选适用项并冻结权重。

## 二、评委实际怎么读（评分动作）

- **摘要外行可读测试**：赛期由队内成员独立读摘要（赛后训练可请外部读者），他能说清"做了什么题、用了什么方法、算出什么结果"才算过；"完整、具体、简洁、与正文一致"符合摘要完整性要求，具体分数按冻结量表评定。→ `abstract.md`
- **每问拆成可观察证据打分**：题目里每个数字要求（"不低于 2.5kg"、"27--33 个单品"）都是一个独立评分点，漏一个扣一处。
- **权重跟随依赖，不跟随问数**：下游复用的基础模型给足分；后续问要有真正的新约束/新粒度/新机制才给新分。
- **典型扣分项**：
  - 自证式验证（验证只是复述拟合结果，没有留出集/反向重构/参数恢复）
  - 黑箱求解（不交代算法步骤、参数、收敛，只写"用 Python 求解"）
  - 表格与正文不一致、公式缺参数说明、结论超出证据
- **第三方训练封顶参考（非官方）**：缺主要任务 → 总分 ≤69；中心模型数学无效 → ≤59。
- **可行性先于最优性**：规划/物理题不可行解即使目标值漂亮也不给高分——先证可行，再谈最优。
- **评委真的会复算**：用结果表/附件交叉核对模型。→ 表列设计必须可复算（见 `modeling-chapter.md` 第七节）。

## 三、出题人视角的扣分清单（2023 C 题评阅综述，可迁移到任何"数据+决策"题）

| 高影响失败 | 迁移到你的题 |
|---|---|
| 销售缺口/异常价未清洗或清洗不合理；均值填充非销售记录 → 扭曲需求 | 清洗每个动作写进 `data-log.md`，理由写清 |
| 分布分析浅：无季节性/节假日/概率拟合 | 数据侧写要做分布拟合与时间效应，不只是直方图 |
| 相关性方法不做适用性检验（Pearson 不检验正态性/线性） | 按统计任务核对适用条件；区分描述相关与推断检验，必要时报告效应量、区间和P值 |
| 耦合决策拆成独立建模（定价与补货分开算） | 题面说"联合"就必须联合建一个模型，别串两个 |
| 忽略"满足品类需求"的多样性/结构约束 | 题意里的每个定性词都转成约束 |
| 决策变量/优化结构不清晰，元启发式不解释 | 目标函数、约束逐条列；启发式给参数与步骤 |
| 结果不可信（利润/定价/补货离谱），无工作日/周末区分 | 结果与常识对照；题面有日期就区分场景 |

**官方封顶锚点**：Q1 只做描述统计+可视化（无分布律）→ 封顶 10/25；耦合关系只用简单回归 → 封顶 7/10。**先做深再写长。**

**官方迁移规则（挑最关键的）**：
1. 每个显式子问题 → 独立可观察的评分项（数据、建模、求解、输出分开验收）
2. 结果被下游复用的问题，权重更高（做扎实）
3. 数据题给"异常/缺失/零销量处理"显式分值——处理选择会实质影响需求估计
4. 耦合题奖励联合机制模型；浅层串行拟合封顶
5. 题面每个数值操作要求 = 一个评分约束
6. 结果必须有场景区分（日期/季节/工作日）
7. "收集更多数据"题按"用途+可行性"双标准评分
8. 官方推荐方法只是锚点不是强制——方法适配+论证充分即可满分

## 四、国一 vs 国二：创新怎么被识别（写作启示）

国一的"超额创新"属于五类之一：**①自创算法 ②跨领域模型融合 ③经典方法的针对性改进 ④建模视角创新（新抽象） ⑤多方法协同框架**。

评审信号清单（S1--S7）压缩成写作要求：

- **针对性**：方法要针对本题特殊结构设计，不是"任何题都能套"
- **动机说明**：非标准方法必须写"为什么这样设计"
- **改进点明确**：用了经典方法要写清"改在哪里、为何改"
- **验证支撑**：创新必须伴随对比验证（改进前后 / 不同方法对比 / 灵敏度）
- **结果优越**：报出"优于常规方法"的具体数字

**突破标志（出现任一即国一档）**：无文献先例 / 针对赛题特殊结构的自创 / 跨领域融合的合理性论证 / 结果显著优越（有对比验证）。

> 核心写作启示：**创新靠"动机说明 + 对比验证"呈现，不靠"创新/改进"等词自我标榜。**
> "真实国一论文的创新常藏在方法组合里，而非靠关键词标榜"——评审不吃形容词，吃证据。

## 五、论文类型与类型化评分

评委先按"结果呈现方式"判断论文类型再评分，用错类型的标准要求自己是自伤：

| 类型 | 结果呈现 | 典型方法 |
|---|---|---|
| A 传统建模型 | 最优解/策略/决策方案 | 规划、博弈、图论、微分方程 |
| B 数据分析型 | 统计图表/相关系数/显著性（为主线） | 回归、聚类、假设检验 |
| C 机器学习型 | 准确率/F1/AUC/混淆矩阵 | 树模型、神经网络（创新重点在特征工程/模型改进） |
| D 工程/信号型 | 工程参数/波形/频谱 | 滤波、仿真（图多、文献偏少是常态，不扣分） |

数据类题目常见类型组合（A 传统建模 / B 数据分析 / C 机器学习）：按结果呈现方式归类，**创新识别跟着主类型走**。

> ⚠️ 注意：本节的 A/B/C/D 是**论文类型**字母，与**题号** A/B/C 无关——两者用同一组字母，阅读时别混淆（论文类型来自官方评审材料，题号来自赛题）。

## 六、权重 → 精力与篇幅的映射

- 摘要 10 + 格式 10 是白送的合规分，最后过 `checklist.md` 与 `paper-review.md` 即可拿稳
- 70--75 分在**假设、建模、求解**上——中心耦合模型（如 2023 C 的 Q2 占 35/100）是得分主体，时间不够先保它
- 5--10 分在**验证、评价、推广、创新**上——性价比高、投入小，但多数队伍会漏
- 推论：**先深后广**。把中心模型做扎实、结果表可复算，比铺开四个浅模型总分高（官方封顶锚点就是证据）
