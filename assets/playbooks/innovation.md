# 创新设计与验证工作流

> 国一 vs 国二的区分线（见 `judge-view.md` 第四节）：识别到创新信号只是第一步，
> 还要判断"突破程度"。**16--18 分是国二扎实组合，19--20 分才是国一超额创新。**
> 本手册回答：拿到题后怎么系统性找到那个"超额创新点"，并把它写到评委认账。

## 一、先认清：创新不是堆名词

评委不吃"创新/改进"这类词，吃**证据**。真实国一论文的创新常藏在方法组合里，
而非靠关键词自我标榜（官方评审经验）。每条创新点必须配齐三件套：

1. **动机说明**——"为什么这样设计"（针对赛题的哪个特殊结构 / 哪个难点）
2. **做法落地**——模型 / 算法 / 抽象层面的具体改动，能写成公式或步骤
3. **对比验证**——改进前后 / 与常规方法的数字对比，证明真的更好

三件套缺一件，创新点就是"声明"，不是"贡献"。

## 二、五种超额创新类型（官方识别清单，对照找切入点）

| 类型 | 典型形态 | 触发条件 |
|---|---|---|
| ① 自创算法 | 针对赛题特殊结构设计、有专门命名的算法 | 题目有"不标准"的结构（初始状态依赖、递归耦合、约束奇特） |
| ② 跨领域模型融合 | A 领域方法用到 B 领域（如博弈论处理路径规划） | 题目决策主体之间有交互 / 对抗 / 信息不对称 |
| ③ 经典方法的针对性改进 | 改交叉/变异算子、改状态转移、改距离定义 | 标准方法在本题某一步明显"不服水土" |
| ④ 建模视角创新 | 新抽象（沙漠地图 → 关键节点有向图） | 原问题结构冗余 / 可压缩，抽象后求解效率跃升 |
| ⑤ 多方法协同框架 | 不同子问题用不同方法，且论证了为什么分治 | 题目各问 / 各子结构性质差异大，单一方法覆盖不了 |

## 三、拿到题后的创新工作流（4 步）

### 第 1 步：找"特殊结构"（拆题时做，写进 question-map）

逐条问自己，把答案写进 `question-map.md` 的"隐含条件"栏：

- 题目的哪个约束是"课本模型没有的"？（例：2020 B"第 0 天补给影响初始状态"）
- 哪个量之间是**耦合**的，标准做法会把它拆开？（例：2023 C 定价-补货必须联合决策）
- 哪个子问题之间的依赖是**递归/时序**的，独立求解会错？
- 数据有什么特殊几何结构？（成分比例和为一、重复测量、分组嵌套）

> 找不到特殊结构就做"扎实组合"（国二档），**不要硬造创新**——硬造的风险
> 是动机说不圆、答辩崩盘，反而不如干净的国二档。

### 第 2 步：选切入路径（对照第二节五类型）

- 特殊结构清晰 → 走 ① 自创算法 / ④ 建模视角
- 有交互/对抗/多主体 → 走 ② 跨领域融合
- 标准方法某步不服水土 → 走 ③ 针对性改进
- 各子结构性质差异大 → 走 ⑤ 协同框架

### 第 3 步：写"创新卡"（每个创新点一张，建模前写）

```markdown
## 创新卡：<名字>
- 类型：①--⑤
- 针对的赛题结构：<哪一条题面/数据特征>
- 动机（2--3 句）：为什么标准做法在这里失效 / 不够好
- 做法：<模型/算法的具体改动，配公式或 Step>
- 验证设计：改进前后对比 / 与基线对比 / 消融——用什么指标、预期什么结论
- 答辩自检：能一句话说清"为什么这样设计"吗？换一道题它还有效吗（有效=通用套用，无效=针对性）？
```

### 第 4 步：过六维审查，验证结果写进"模型的分析与检验"章

创新点和其他模型一样要过 `model-review.md` 六维审查；其验证结果集中写进
检验章（见 `validation-sensitivity.md`）——**"结果显著优越"是四个突破标志之一，
必须用数字呈现**（"准确率提升 10%+""收益提升 20%+""收敛快 3 倍"这类对比）。

## 四、四个"突破标志"自检（命中任一即国一档，写在摘要/结论的素材）

- 🅰 **无文献先例**：方法在现有文献里没有直接对应物——写法："现有方法均假设 X 独立，
  本文针对本题 X 与 Y 耦合的结构，提出……"
- 🅱 **针对赛题特殊结构的自创**：方法专门为本题设计，换题就不适用——写法："该结构
  是本题特有，故本文设计专用算法 Z……"
- 🅲 **跨领域融合的合理性论证**：有明确的"为什么这样融合"——写法："问题三本质上是
  多主体决策，故引入博弈论中的……，其合理性在于……"
- 🅳 **结果显著优越**：有对比验证的数字——写法："较常规 SA 算法，本文算法在 10 次
  随机算例上平均提升 12.3%，且方差更小（表 X）"

## 五、禁忌

- [ ] 不为凑创新堆名词（"创新性融合 XGBoost 与灰色预测"——没有动机就是扣分项）
- [ ] 创新点不写动机（评委 S2 信号不命中 → 置信度降级 → 不给高分）
- [ ] 创新点无对比验证（S5 不命中，突破标志 🅳 无从谈起）
- [ ] 硬造创新导致模型合理性受损（假设 20% 分先保住，再谈创新 25% 分）
- [ ] 用"显著""新颖"等形容词替代数字
