# 符号说明

依据 S13、S15。从已经使用的公式提取符号，不从范文移植变量。

## 工作记录与论文表分开

`05-paper/symbol-register.md` 记录符号、类型、含义、单位、范围、下标、首次位置与代码变量对应。正文表仅收全局或反复使用的主要符号，用 booktabs 三线表，列“符号、含义、单位”。局部一次性符号在首次公式附近解释；min、max、ln、exp 等运算符通常不入表。

优先沿用领域惯例。区分标量、向量、矩阵、集合，以及大小写、上下标。含义应写明研究对象和索引；量纲必须与数据和代码一致，无量纲统一标“无量纲”。百分数与0—1数值分开说明。首次出现仍需简要定义，表不能替代局部解释。

符号冲突先登记影响，确认改名后同步正文、代码映射、图表和公式；不单独改表造成假一致。缺单位或定义时列待确认，不猜测。

## 可复制提示词

> 从当前论文公式、变量定义、数据单位和代码接口提取符号，先报告同符异义、同量异符、大小写、下标、量纲与数值范围冲突。填写 symbol-register，只将全局主要符号输出为 LaTeX 三线表。局部符号给出首次定义位置建议。保留已经稳定的符号，改名先列影响范围；不虚构单位、定义或程序对应。

## 验收

- [ ] 表中每个符号在正文实际使用，所有公式符号在表中或就近定义。
- [ ] 元/万元、m/km、天/小时、百分数/小数等换算一致。
- [ ] 表题在上、无竖线、含义可读；表号随全文统一规则。
- [ ] 自定义指标先定义计算口径和意义，再列符号。
