# 问题重述

依据用户材料 S09、S11，并参考整套模板 S03、S04。只转述任务；保留研究对象、范围、单位、精度、硬约束和指定输出。

## 写作步骤

1. 从 `01-problem/question-map.md` 按原题顺序抽取全部问题与子任务，对照题面补齐遗漏。
2. 研究背景用短段说明对象、现实情境与核心矛盾，避免扩写未经核验的行业、政策和趋势。
3. 问题回顾逐问写“需要计算、比较、解释、预测或设计什么”，不要提前给模型、算法和答案。
4. 研究综述可选。已有真实且相关文献时，概括方法、适用任务和局限，接到本题；没有文献时先登记缺口，不编造作者或引用。

一般以半页至一页完成必要重述；加综述可用一至两页。约500字综述是参考材料的建议，不是必写内容。

## 可复制提示词

> 根据完整题面、附件说明和 question-map，整理“问题重述”。用自己的语言保留全部对象、时间空间范围、关键条件、单位精度和交付物，按原题顺序列任务。背景简洁；不提前出现选用模型、求解过程和结果。只有提供且核验过相关文献时才写研究综述。输出 LaTeX 正文，以及单独的“原题任务—重述位置—遗漏或歧义”对照；缺信息不补造。

## 验收

- [ ] 每个子任务都有对应表述，未弱化“必须”“比较”“解释”等要求。
- [ ] 未把相互独立的问题写成递进关系，未扩展允许数据范围。
- [ ] 未照抄整段题面或复制非必要原题图表。
- [ ] 背景事实与研究综述均可核验，文献已进入 reference-register。
