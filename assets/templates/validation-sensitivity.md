> 把全篇的**检验**（误差 / 对比 / 现实认知）与**灵敏度分析**集中放这一章，
> 不分散到各问建模章里。这是评委验证"模型靠不靠谱"的章节，含金量高、答辩好守。

## 10.1 模型的检验

### 误差 / 精度检验（预测类必备）

- 指标按模型性质选：回归 / 预测常用 **MAE、RMSE、MAPE**；分类用准确率 / F1
- 必须给**留出集**或交叉验证的数字，不能只报训练集误差
- 写法：一句数据切分说明（"取后 20% 数据作测试集"）→ 指标公式（带编号）→ 指标表 → 2--3 句解读（"MAPE 均在 10% 以内，预测精度满足后续决策需求"）

### 对比验证

- 选 1--2 个合理基线对比：朴素模型（历史均值 / 同期值）、不同方法（GM(1,1) vs ARIMA）
- 一张对比表（方法 / MAE / RMSE / MAPE）→ 一句结论（"XGBoost 各指标均优于 GM(1,1)，故选其作为最终模型"）
- **先精确解后启发式的题**：启发式结果与精确解对比（小规模算例），误差 <5% 即算过

### 现实认知检验

- 结果与业务常识对照：销量高峰在夏季、损耗率随温度上升——模型输出与之相符
- 与文献 / 公开数据对照：量级一致即可，不强行找文献

## 10.2 灵敏度分析

### 什么时候做

有**参数 / 权重 / 资源量**的模型都要做：优化模型的系数与资源约束、评价模型的指标权重、预测模型的超参。
纯确定性推导且无自由参数的模型可只做误差检验。

### 方法：参数扰动法（最常用、答辩最好守）

1. **挑关键参数**（2--4 个）：目标函数系数（价格、成本、损耗率）、约束右端（库存上限、销量上限）、评价权重
2. **定扰动范围**：±5%、±10%、±20% 三档（按参数现实波动范围取，别取到物理不可能的值）
3. **逐参数扰动**：固定其他参数，只动一个，重算目标值 / 排序 / 预测值
4. **呈现**：扰动表（参数 / -20% / -10% / 0 / +10% / +20% → 目标值或指标）+ 一张折线图（多参数各一条线）
5. **结论**："目标值随 X 在 ±10% 内变化不超过 3%，模型稳健；Y 超过 +10% 后结果明显变差，说明 Y 是关键参数，决策时需重点获取其准确值"

### 评价类模型的权重灵敏度

- 方法一：**权重扰动**——关键指标权重 ±10% / ±20%，看重排序是否翻转
- 方法二：**换权对比**——熵权法结果与等权、AHP 权重结果对比，排序一致则稳
- 结论报"排序稳定性"而不是"分数稳定性"（评价题评委看的是排序）

### 禁忌

- [ ] 只有图没有数字：折线图必须配扰动表，结论必须报变化幅度（"变化 <3%"）
- [ ] 不做灵敏度就直接写"模型稳健"
- [ ] 扰动范围拍脑袋取到不可能的值（价格 -50%）——先交代"按参数现实波动范围取 ±X%"

- [ ] 灵敏度结论与"评价、改进"章节重复（这里报稳健性，那里报改进方向）
