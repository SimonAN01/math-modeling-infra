## 〇、这一章到底在回答什么

评委读这一章只找三样东西：

1. **为什么这么建**——每个公式 / 约束 / 参数的依据（题面哪句话 / 数据什么特征 / 什么常识）
2. **模型长什么样**——假设 → 符号 → 变量关系 → 目标 / 约束，评委能自己复算
3. **算出什么、说明什么**——数值 + 一句解释，与题面或常识对得上

三样缺一样，这章就是空架子：有模型没依据 = 拍脑袋；有依据没结果 = 没做完；有结果没解释 = 评委看不懂。

## 一、章节骨架

```
问题 X 模型的建立与求解
├── 章首导语（可选，≤ 2 句：本章做什么、与前后问衔接）
├── 前置小节（可选 1 个）：数据预处理 / 所用方法介绍
├── 二级标题 1：第一问：<方法+内容>（如"Pearson 相关系数判断线性关系"）
├── 二级标题 2：第二问：<方法+内容>
└── …（子问题数 = 二级标题数）
```

## 二、行文展开的底层逻辑：一条叙事链 + 四个动作

每个子问题小节内部，行文沿同一条链展开——但**不能每节都用同一句式**（见第十节"结构变奏"）：

```
依据（为什么这样做）
  → 做法（模型 / 公式 / 算法，带编号）
  → 结果（表 / 图 / 数值）
  → 解读（这个数字说明什么，2--3 句，与题面或常识对得上）
```

四个动作缺一不可，但**比例随内容变**：数据筛选节"依据"1 句即止；方法引入节"做法"重；结果节"解读"重。本节是铺垫型还是结论型，决定节奏是 1:2:1:2 还是 1:3:2:2，不搞平均主义。

### 章内节间接力

上一节的输出就是下一节的输入，行文要显式接上：

- 坏："对数据聚类后，建立优化模型……"（聚类结果是什么？怎么用的？没说）
- 好："6 个品类中，品类 2 的销量波动最大（变异系数 0.41），补货时对其单独加设安全库存约束……"

## 三、"有理有据"：依据的三类来源

全章所有"为什么"必须落到三类来源之一。**写不出来源的公式 / 约束 / 参数就是拍脑袋，删掉或补依据**：

| 来源 | 例子 | 行文位置 |
|---|---|---|
| 题面硬要求 | "单品每次补货量不低于 2.5kg" | 约束后一句："由题意，……" |
| 数据规律 | "损耗率取三年均值 4.7%（见 5.3 节）" | 参数后一句，指到数据侧写 |
| 业务常识 / 文献 | "定价不低于单位成本 110% 以保证盈利" | 目标或约束后一句 |

依据句式三例：

- 题面："由题意，单品补货量不低于 2.5kg，故有约束 x_i ≥ 2.5。"
- 数据："5.3 节显示损耗率稳定在 4.5%--5.0%，此处取三年均值 4.7% 作为 L。"
- 常识："商超定价通常为成本的 1.1--1.5 倍，故限定 1.1c_i ≤ p_i ≤ 1.5c_i。"

**每个参数报数值、报出处**："取 α=0.95"是 AI 腔；"初始温度 100℃、衰减系数 0.95（经验取值，参数讨论见 8.2.3 节）"是论文。

## 四、小节内部三步走（每个子问题小节）

1. **引入句 = 依据句**（1 句）："由于……（数据特征 / 题目要求 / 业务常识），因此本文采用 X 方法"——点明为什么选它，不写方法历史
2. **公式**（直接给，带编号）：公式后一句符号解释（"其中 S_ij 表示……"）
3. **结果**（表 / 图 + 2--3 句解读）：解读只讲关键点——谁高谁低、什么规律、**与常识或题面是否一致**——然后立即收尾

## 五、问题一~三的建模思路模式（C050 国一打法）

C 题前三问通常是"数据关系题 → 预测+决策题 → 复用型决策题"，各有固定打法：

### 模式 A：数据关系类（如问题一）

```
数据预处理（一句） → 描述统计量（均值/标准差/偏度/峰度，公式+表）
→ 可视化（直方图/饼图/趋势图，图+2-3 句解读）
→ 相关性分析（Spearman 或 Pearson，公式+相关系数矩阵表）
→ 显著性检验（Step1 假设 → Step2 P 值 → 结论）
→ 聚类（K-means++，Step1-6 伪代码+公式）→ 聚类中心表+结果表 → 逐类解读
```

- 两个统计量公式（偏度、峰度）各配"一句定义 + 一句含义解读"，不展开
- 相关系数矩阵用 I. II. III. 逐条解读（谁强正相关、谁近似无关）
- **显著性检验是国一标配**：几乎每个统计方法后都跟"Step1 提出假设 → Step2 计算 P 值 → 拒绝/接受原假设"

### 模式 B：预测+决策类（如问题二）

```
方法引入小节（如成本加成定价：一句定义+公式+文献引用）
→ 第一问：相关检验（Pearson 公式+结果表 → P 值检验）→ 回归（公式+回归表+方程）
  → 解读经济含义（"销量每升 1kg，定价降 0.038 元"）
→ 第二问：时序预测（模型选型表：简单季节性/温特斯乘性 → 平滑方程公式 → 参数解释表）
  → 单位成本计算（B = C×(1+L)）
  → 目标函数（利润最大化：收入 − 损耗，一句业务含义先行）
  → 约束逐条（①需求 ②补货 ③定价 ④损耗：一句理由+公式）
  → 优化模型整合（max ... s.t. {...}）
  → 启发式求解（模拟退火：一句思想+Metropolis 公式+Step1-5+求解参数一句）
  → 预测图/表 → 最终策略表（补货量+定价）→ 结果数字
```

- **预测模型选型要交代**：表 10 列出各品类用的模型名（简单季节性/温特斯乘性）
- 最终结果必须给数字（"最大收益 5105.60 元"），摘要与正文一致

### 模式 C：复用型决策类（如问题三）

```
数据预处理（筛选日期范围、筛选条件）→ 目标函数（引入 0-1 变量，一句解释含义）
→ 新约束逐条（①种类数量 ②陈列量 ③最高补货量 ④定价区间）
→ 优化模型整合 → 模型说明（一句复用理由："仍为线性规划问题，故仍选用模拟退火"）
→ 求解参数一句 → 结果表（29 种单品：单位成本/补货量/定价/收益）→ 结果数字
```

- **模型复用写法**：不重新介绍算法，一句"仍选用 X 模型求解"（8.2.2）
- 结果表列设计让评委可复算（单位成本 → 收益可验）

## 六、模型建立部分的写法

- **目标函数**：先一句业务含义（"由题意……使总收益达到最大，即目标函数为"），再给 `max/min` 表达式
- **约束逐条编号 + 一句业务理由 + 公式**：①需求约束 ②补货约束 ③定价约束 ④损耗约束……
- **约束的来源只有三类**（写理由时对号入座，见第三节）：
  - 题面硬性要求（如"单品每次补货不低于 2.5kg"）
  - 数据规律（如"不超过前三年日最大销售量"）
  - 业务常识（如"定价不低于单位成本 110%、不高于 150%"）
- **假设必须在正文"兑现"**：模型假设章写的每条假设，都要在本章某个公式 / 约束里出现一次；兑现不了的假设就是凑数，回假设章删掉
- **符号与公式一一对应**：公式里出现的符号都能在符号表找到，符号表里收的符号都在正文出现过
- **引入新变量**（如 0-1 变量 y_i）时一句话说明含义和取值
- **全部列完后整合**：`max ... s.t. { ... }` 一个总模型呈现（7.3.2 / 8.2.1 写法），不重复罗列

## 七、模型求解部分的写法

- **复用模型**：一句"本题仍为……问题，故仍选用 X 模型求解"（8.2.2 写法），不重新介绍算法
- **求解参数一句话交代**："设定初始温度 100℃、温度衰减系数 α=0.95、每温度迭代最多 100 次，采用 MATLAB 求解"
- **结果表可核验**：表列设计让评委能复算——如"序号 / 单品名称 / 单位成本 / 补货量 / 定价 / 收益"（每行成本已知 → 收益可验）
- **篇幅处理**："由于篇幅有限，只展示前 15 种……其余见附件"，不解释、不道歉
- **摘要数字必须与正文结果表一致**（5105.60 元、1282.2631 元这类数字，摘要、正文、结果文件三处一致）

## 八、算法写法

- 一句思想 + 关键公式（如 Metropolis 准则 p_t 表达式）+ Step1--5 伪代码（每步一句话）
- 参数一句话即可，不做收敛性理论讨论

## 九、软问题（数据 / 建议类，如问题四）写法

- 章首一句定路线："本文将通过模型分析和文献查阅两种方式提出合理建议"
- 指标构造逐个给理由：特征单品选取（"选三年销售总量最多的单品"）、节气 / 节日窗口（"立春立夏立秋立冬处于季度中心，取前后一周销量"）
- 数据源逐个写：**一句数据说明 + 业务用途**（客流量 → 调整陈列与促销时段；退货 → 识别质量问题与不受欢迎商品……）
- 结尾总结 1 段（≤ 3 句）即止

## 十、去 AI 味：八条特征 + 改写对照

### AI 味的八条特征（症状 → 为什么被识破 → 改法）

1. **万能总结句**："综上所述，本节……""该模型具有良好的性能与推广价值"
   → 评委会读但没获得任何信息，且这是大模型最高频句式。
   → 改法：删掉；章节结尾就是最后一个结果表 / 图，或把总结换成一句具体数字。
2. **三段式排比与序号腔**："首先……其次……最后……"
   → 三连排比是人写论文少见的节奏，出现即暴露。
   → 改法：拆开写，动作主语换成"数据 / 题意 / 常识"，每句独立成段或长短错开。
3. **同构段落**：相邻段落句法、长度雷同（都是"由于……因此……"，都 3 行）
   → 节奏可预测 = 机器特征。→ 改法：见本节"结构变奏三原则"。
4. **空洞程度副词**："显著""有效地""科学合理""很好地"
   → 人写论文用数字说话，不用副词表态度。→ 改法：副词换成数字（"显著提升"→"提升 8.3%"）。
5. **概念空转**：只报方法名（"采用熵权法、TOPSIS 综合评价"），不落到本题对象与数字
   → 评委无法复算，且是典型"知道名词不知道题"的 AI 腔。→ 改法：方法名后面必须跟本题数字或本题对象。
6. **过度衔接腔**："值得注意的是""不难发现""与此同时""进一步地"
   → 大模型高频衔接词，人写论文几乎不用。→ 改法：删，直接说内容。
7. **报告 / 预告腔**："本文将……""下面我们将介绍……""接下来，我们……"
   → 论文不是演讲稿，评委要的是结果。→ 改法：删掉预告句，直接上内容。
8. **罗列不解释**：公式 / 图表 / 步骤连续抛出，中间无一句解释
   → 机器生成的结构是"公式-公式-公式"，人的结构是"为什么-是什么-说明什么"。→ 改法：每个公式前后各补一句（依据 + 符号解释），每个图表配 2--3 句解读。

### 改写对照（AI 味 → 人写 → 为什么后者像人写的）

**例 1：万能总结句**
- AI 味："综上所述，本文建立的优化模型能够有效地解决补货与定价问题，具有良好的实用性和推广价值。"
- 人写："该策略下 29 种单品总收益为 5105.60 元，较按品类统一定价提高 8.3%。"
- 为什么像人写的：删掉态度句，只留一个可复算的数字；数字是人的锚点，态度词是 AI 的锚点。

**例 2：三段式排比**
- AI 味："首先，我们对数据进行预处理，剔除了异常值。其次，我们采用 Spearman 相关系数分析变量间的相关性。最后，我们利用 K-means++ 算法对单品进行聚类分析。"
- 人写："退货记录单价为负，属无效数据，直接剔除（共 12 条）。Spearman 相关显示销量与损耗率相关（r=0.71，p<0.01）。据此对单品做 K-means++ 聚类，得到 6 类。"
- 为什么像人写的：无"首先/其次/最后"，每句自带依据和数字，句长错落。

**例 3：公式不挂依据**
- AI 味："目标函数为 max Z = ∑(p_i − c_i)x_i，其中 p_i 为定价，c_i 为单位成本。"
- 人写："单品 i 每销售 1kg 盈利 (p_i − c_i)，单位成本 c_i = C_i(1+L_i)，L_i 为该品类的历史损耗率（见表 5.3）。故目标为最大化总收益 max Z = ∑(p_i − c_i)x_i。"
- 为什么像人写的：每个符号都有出处（C_i 是什么、L_i 从哪来），逻辑从业务流向公式，而不是公式凭空出现。

**例 4：预告腔**
- AI 味："下面我们将详细介绍模型的求解过程，首先给出算法的基本思想，然后说明具体步骤。"
- 人写：（直接进入）"求解用模拟退火。初始温度 100℃，衰减系数 0.95，每温度迭代 100 次；接受概率按 Metropolis 准则 p_t = exp(−ΔE/T)……"
- 为什么像人写的：删掉全部预告，直接干活——评阅 30 页论文，评委没有耐心读路标句。

**例 5：概念空转**
- AI 味："本文采用熵权法确定权重，并结合 TOPSIS 进行综合评价，结果科学合理。"
- 人写："熵权法得三项指标权重 0.52 / 0.31 / 0.17，其中年销售额权重最高；TOPSIS 综合得分前三名依次为 A、B、C，A 以 0.83 分居首。"
- 为什么像人写的：方法名全部落到本题数字上；"科学合理"这种自证词消失。

### 结构变奏三原则

- **相邻两段的第一句句法不要相同**：一段用"由题意……"起，下一段直接上公式，再下一段以数字开头
- **段落长短错开**：依据句 1 行、公式段 2--3 行、结果解读 2 句；全节不要"齐刷刷四段等长"
- **每节至少一处数字落地**：参数值、样本量、结果数——数字是人写作的锚点，也是评委可复算的抓手

## 十一、与 humanizer-zh 的分工

- 本模板管**结构与内容层**：删哪类句子、依据怎么挂、数字怎么落地
- `humanizer-zh` 管**词汇层**：AI 高频词替换、句式润色
- 顺序：先按本模板写 → 对照第十节清单自查 → 再过 humanizer-zh

## 十二、禁忌清单

- 不写"我们建立了……模型，模型具有良好的……"套话
- 不写"综上所述，本节……"章节总结段——章节结尾就是最后一个结果表 / 图
- 不重复第二章问题分析已写的"为什么这样建模"
- 不写方法历史、不做理论推导、不解释定义来源
- 不为凑字数堆假设、堆符号、堆公式（公式按复杂度 1-2 / 3-4 / 5-8 个）
- 不用"模型准备"写空泛过渡句（只写数据展开、参数代入、集合构造）
- 不出现"首先 / 其次 / 最后"三段式排比、"值得注意的是"等衔接腔、"本文将"预告腔
- 不用程度副词替代数字（"显著""有效""科学合理"）
- 只报方法名不报数字的"概念空转"写法
- 公式前后无依据、无符号解释的"裸公式"

- 附录 2：补充表格、图片（正文因篇幅放不下的）
- 附录 3：代码（完整可运行源程序）
