# 论文质量审查

与提交清单分工：本页查内容与证据，`06-submission/checklist.md`查交付合规。可评分的完整评审见 `guides/review-rubric.md`；输入不齐只做诊断。赛期审读与确认限队内，赛后训练可接受教师反馈。

## 题意与章节

- [ ] 重述保留所有子任务、硬约束、单位、精度及指定文件，背景和综述不虚构。
- [ ] 分析解释数学类型、数据限制、路线理由、真实依赖和验证计划；不提前报结果，不要求一问一个小节。
- [ ] 共用/专属数据位置合理，已处理事实有 data-log，计划没有写成完成。
- [ ] 假设已由团队确认，必要、有依据、在模型或检验中有作用，无循环论证。
- [ ] 主要符号在表中，局部符号就近解释；单位、下标、范围及代码映射一致。

## 模型、求解与答案

- [ ] 每问有实际数学表达与题目适配依据，关键推导不断链，参数来源可核验。
- [ ] 目标、约束、边界、初值与变量范围完整；近似与简化影响已说明。
- [ ] 算法与问题匹配，参数、种子、停止条件、求解状态明确，最优性声明有证据。
- [ ] 每问输出直接回答原任务，结果单位、精度、图表与指定结果文件一致。
- [ ] 有与题型匹配的独立验证、基线或回代，未以模型自身证明正确。
- [ ] 灵敏度扰动选择有依据，区分检验、敏感性、稳健性与误差分析；没有机械要求所有题做同一实验。
- [ ] 优点有证据，局限具体，未来改进不当作已完成成果。
- [ ] 每个摘要/正文定量结论已在 evidence-map 对账，变更传播已清账。

## 文字与排版

- [ ] 摘要最后反写、覆盖各问且可独立理解，未强造任务间递进关系。
- [ ] 图表均有编号、引用、单位及解读，无无意义重复或过小字；关键结果保留在正文。
- [ ] 引文真实、相关、首次引用顺序一致，不设虚构的文献数量下限。
- [ ] 表述简洁、必要的理论解释保留；humanizer-zh未改变数值、单位、方法和结论。
- [ ] main.tex完整编译两遍，PDF字体、分页、交叉引用无异常；无模板提示、讲解配色和目录。

## 复现与收口

- [ ] 附录支撑清单、完整源码、实际包内文件版本一致，包含必要公共模块和软件命令。
- [ ] 新目录解压后的程序可按运行说明复现，输入位置、依赖、参数和输出齐全。
- [ ] AI声明与真实台账及详情一致，人工确认不是AI代填。
- [ ] 摘要之后到附录之前的全部页面计入正文，包括AI声明和参考文献。
- [ ] 实际PDF、附件、代码注释、截图及元数据已检查匿名性。
