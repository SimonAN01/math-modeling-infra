# Paper Review

> Review Lane：自审 / 老师审稿后修改 / 答辩前总检查。
> 与 `06-submission/checklist.md` 分工：那份管"提交合规"，这份管"论文质量"。
> 答辩前和老师审稿后各过一遍，逐项打勾。

## 自审（写完初稿过一遍）

- [ ] 题意是否被正确拆解，题型判断是否准确
- [ ] 模型假设是否支撑模型（少而硬，不写自证话术）
- [ ] 符号是否全篇统一，符号表是否完整
- [ ] 公式推导是否断链（公式数量按复杂度控制，不堆公式）
- [ ] 求解方法是否和模型匹配（精确解优先，启发式有收敛说明）
- [ ] 结果是否有验证（误差指标 / 现实认知 / 交叉验证）
- [ ] 灵敏度分析是否完整（关键参数、扰动范围、稳健区间）
- [ ] 题目对照验证是否逐项完成（每问都有对应建模和输出）
- [ ] 图表是否服务结论、风格整篇统一、符合中文学术图规范
- [ ] 参考文献是否真实可核验（4--10 篇，正文有标注）
- [ ] 首页标题已替换，无模板提示语 / 彩色批注 / 讲解笔记残留
- [ ] 分问题建模章节没有重复第二章"问题分析"的内容
- [ ] "模型准备"写的是数据、索引、参数整理，不是空泛过渡句
- [ ] 算法环境前后有解释正文，算法调用对象与输出对象写清
- [ ] 优化模型统一 `s.t.` + 大写目标符号 + 紧凑大括号约束
- [ ] 结论只总结已证明内容，按问数逐段对应
- [ ] 中文正文无明显 AI 痕迹 / 模板腔（humanizer-zh 已过）

## 最终收口（提交前）

- [ ] 主入口来自 `example.tex` 或其复制的 `main.tex`，`cumcmthesis.cls` 正常调用，XeLaTeX 编译
- [ ] 摘要为最后反写版本，1 页内，逐问给了结果数值
- [ ] 电子版用 `\documentclass[withoutpreface,bwprint]{cumcmthesis}`（去掉承诺书/编号页）
- [ ] 所有 `label / cref / cite` 对应正确
- [ ] 目录、书签、页码、附录与正文一致（2026 规范正文不要目录）
- [ ] 附录、计算结果文件、支撑材料三者分工合理，没有该进附件却塞进论文的内容
- [ ] 批量 `\input{}` 的长表、代码、图片实际进入了最终 PDF
- [ ] 正式 PDF 来自主目录完整编译结果（编译 2 次以上），不是临时检查产物
- [ ] Python 结果可由 `handoff.md` 记录的 `uv run ...` 命令复现
- [ ] 支撑材料目录和文件名能一眼对应到子问题，无残留 `md/txt/log` 无关文件

## 紧急情况处理

- **模型审查不通过**：暂停编码和写作，回到 `question-map` 与隐含条件检查重做假设、变量和约束；连续三轮不过，强制重新拆题
- **代码结果不合理**：先查数据口径、单位、边界条件、约束方向、随机种子、目标函数符号，再改代码
- **LaTeX 编译失败**：优先定位最近修改的 `\input{}`、图表路径、未闭合环境、中文编码、参考文献和交叉引用
- **时间紧迫**：保留能回答题目的主模型、核心验证、必要图表和题目对照；压缩背景、重复推导、装饰性图片
- **页数超限**：先做 page-budget，把全量明细迁入附录 / 计算结果文件 / 支撑材料，正文保留代表性结果
