# Checklist

> 赛前 48h + 提交前检查清单。逐项打勾，不打勾不交卷。

## 赛前 48h（开赛前）

- [ ] 三个 skill 就位（math-modeling-infra / scientific-figure-making / humanizer-zh）
- [ ] CUMCMThesis 模板能编译出空白 PDF（XeLaTeX 环境正常）
- [ ] uv 环境就位，依赖本地化（离线也能 `uv run`）
- [ ] 官方文档 / 历年优秀论文已下载（断网预案）
- [ ] AI 工具可用性确认 + 账号登录态
- [ ] 数据下载渠道确认（赛题附件入口）
- [ ] 分工确认：建模 / 编程 / 写作，写作手不坐等

## 开赛后 3 小时

- [ ] problem-brief 九要素填完
- [ ] question-map 每问一张表
- [ ] submission-rule 提取完毕（交什么、怎么命名、限页没有）
- [ ] 题型判断：预测 / 评价 / 优化 / 组合

## 提交前 2 小时

- [ ] 论文最终 PDF 完整编译一次，目录 / 页码 / 交叉引用正常
- [ ] 摘要 1 页内、逐问给了结果数值
- [ ] 定稿前 humanizer-zh 已过（正文 + 摘要 + 模型评价）
- [ ] 结果文件字段名、单位、顺序与官方模板一致
- [ ] 论文数字 = 结果文件 = 支撑材料，三方对得上
- [ ] 支撑材料目录命名干净（无 final_v2 / 副本 / 临时）
- [ ] 承诺书签名；AI 工具使用按规则说明
- [ ] 压缩打包、按规则命名、上传成功、对方能打开

## 红线（碰到就是判负风险）

- [ ] 论文、结果文件、支撑材料三者数字对不上 —— 必须核对
- [ ] 结果只写在论文里、漏填官方 xlsx —— 必须补
- [ ] 引用了编造文献 / 伪造数据 —— 必须删
- [ ] 摘要含前文没证明的新判断 —— 必须删
