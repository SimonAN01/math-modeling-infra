# Checklist

> 赛前 48h + 提交前检查清单（对齐 2026 国赛规范）。逐项打勾，不打勾不交卷。

## 赛前 48h（开赛前）

- [ ] 三个 skill 就位（math-modeling-infra / scientific-figure-making / humanizer-zh）
- [ ] CUMCMThesis 模板能编译出空白 PDF（XeLaTeX 环境正常）
- [ ] uv 环境就位，依赖本地化（离线也能 `uv run`）
- [ ] 官方文档 / 历年优秀论文已下载（断网预案）
- [ ] AI 工具可用性确认 + 账号登录态；**记下 AI 工具名称与版本**（写 AI 声明要填）
- [ ] 数据下载渠道确认（赛题附件入口）
- [ ] 分工确认：建模 / 编程 / 写作，写作手不坐等

## 开赛后 3 小时

- [ ] problem-brief 九要素填完
- [ ] question-map 每问一张表
- [ ] submission-rule 提取完毕（交什么、怎么命名、30 页 / 20MB 红线）
- [ ] 题型判断：预测 / 评价 / 优化 / 组合

## 提交前 2 小时

- [ ] 论文最终 PDF 完整编译一次，页码 / 交叉引用正常（**无目录**）
- [ ] 摘要 1 页内、逐问给了结果数值、无需英文翻译
- [ ] 定稿前 humanizer-zh 已过（正文 + 摘要 + 模型评价）
- [ ] 电子版第一页 = 摘要专用页（承诺书 / 编号页未混入）
- [ ] 参考文献之前有 AI 工具使用声明（二选一，原文抄录）
- [ ] 用 AI → 支撑材料含 AI工具使用详情.pdf（工具名/版本、用途环节、提示方式、人工核验情况）
- [ ] 正文 ≤ 30 页；附录含支撑材料文件列表 + 全部可运行源码（或注明"本论文没有用到程序"）
- [ ] 论文 PDF ≤ 20MB 且未压缩；支撑材料 RAR/ZIP ≤ 20MB
- [ ] 结果文件字段名、单位、顺序与官方模板一致
- [ ] 论文数字 = 结果文件 = 支撑材料，三方对得上
- [ ] 全文（含附件名、文件名、代码注释）无身份 / 学校 / 赛区信息
- [ ] 支撑材料目录命名干净（无 final_v2 / 副本 / 临时）
- [ ] 纸质版承诺书签名
- [ ] 压缩打包、按规则命名、上传成功、对方能打开

## 红线（碰到就是判负风险）

- [ ] 论文、结果文件、支撑材料三者数字对不上 —— 必须核对
- [ ] 结果只写在论文里、漏填官方 xlsx —— 必须补
- [ ] 引用了编造文献 / 伪造数据 —— 必须删
- [ ] 摘要含前文没证明的新判断 —— 必须删
- [ ] AI 使用隐瞒 / 虚假声明 / AI 内容未经人工审查 —— 取消评奖资格
- [ ] 支撑材料与论文内容不符 —— 取消评奖资格
- [ ] 竞赛期间与队外任何人（含指导教师）交流赛题 —— 严重违纪
