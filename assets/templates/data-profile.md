# 数据侧写章节写法（第五章）

> 数据题的第五章：回答"**处理完的数据长什么样、分布如何**"，为后续建模铺路。
> 与问题分析章节里"数据预处理小节"的分工：那里回答"数据有什么特征、为什么这样处理"；
> 这里回答"处理完之后数据的全貌画像"。写法细则见 `paper-outline.md` 数据侧写一节。

## 何时启用

有附件数据（尤其数据量大、品类多、字段杂的题）时启用；纯推导题不写这一章。

## 章节结构

```
五、数据侧写
├── 开头 1 段：为什么提前做数据分析
│     （数据庞大复杂，需先了解整体情况，便于后续问题分析与建模）
├── 5.1 <画像主题一>     每节：1 个表/图 + 1--2 句结论，即止
├── 5.2 <画像主题二>
├── 5.3 <画像主题三>
└── （2--4 个小节为宜，不再多）
```

## 小节主题怎么选（核心原则）

**每个小节都必须直接支撑后续某一问的建模**，写之前先回答"这节支撑谁"：

| 小节主题示例 | 支撑哪一问（国一 C050 实证） |
|---|---|
| 5.1 品种丰富度 | 支撑问题四的指标构造 |
| 5.2 季度销量分布 | 支撑问题一的分布规律、问题二的预测模型选型 |
| 5.3 损耗率画像 | 直接支撑单位成本公式 B=C(1+L) |
| 5.x 缺失 / 异常整体情况 | 支撑数据预处理方案与假设"有效数据假设" |

**每节末尾用一句括注式的话点明用途**（"该规律将为 5.2 节损耗率参数取值提供依据"），
让评委一眼看到"侧写不是白写的"。

## 每节写法：1 个表/图 + 1--2 句结论

- 描述统计（均值 / 标准差 / 偏度 / 峰度）一张三线表 + 一句解读（"销量右偏，多数品类销量集中在中低区间"）
- 分布图（直方图 / 饼图 / 趋势图）一张 + 一句规律（"销量呈明显季节性波动，夏季为高峰"）
- 相关性矩阵一张表 + 按 I. II. III. 逐条解读关键相关对
- **图/表必须过 `scientific-figure-making`**：中文、风格统一、标数值

## 禁忌

- [ ] 不做与建模无关的数据罗列（"附录级"明细不放这里，放支撑材料）
- [ ] 不与问题分析的数据预处理小节重复（那边讲"怎么处理"，这边讲"处理后长什么样"）
- [ ] 不与问题一建模章的数据关系分析重复（那边是模型求解的一部分：显著性检验、聚类；这边是全景画像）
- [ ] 每节超过"1 表/图 + 2 句"的篇幅（国一 C050 的侧写极克制）

## 自检

- [ ] 每个小节都能说清"支撑哪一问的哪一步"
- [ ] 每节只有 1 个表或 1 个图，结论 1--2 句
- [ ] 数据口径与 `02-data/data-log.md` 一致（均值、样本量、单位）
